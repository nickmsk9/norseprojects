# norseprojects

Для локального запуска откройте Docker (например, OrbStack) и выполните в папке проекта:

```sh
docker compose up -d
```

Откройте [http://localhost:8080/](http://localhost:8080/). Стартовая страница находится в `public/index.php`.

Чтобы остановить сервер, выполните `docker compose down`.
